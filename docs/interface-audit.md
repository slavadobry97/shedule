## HIGH — чинить первыми

### 1. Горизонтальная прокрутка на 320px — ИСПРАВЛЕНО 24.10.2026

- **Где:** `components/schedule-view.tsx:273-284` — панель даты и навигации
  (`ml-auto flex flex-col items-end`): заголовок недели `whitespace-nowrap`
  («19.10.2026 – 25.10.2026») и ряд кнопок не переносятся.
- **Факт:** замер в браузере — `scrollWidth` 399px при клиентских 305px
  (94px переполнения).
- **Фикс (выполнен, согласован с человеком):** [‹ Сегодня ›] собраны в пилюлю
  в стиле переключателя вида (ghost-кнопки в `rounded-full border bg-muted p-0.5`);
  строка `flex-wrap`; высота тач-целей 40px (осознанный компромисс ниже HIG-44,
  выше WCAG-AA 24 — чтобы пара пилюль помещалась в 320px); сегменты переключателя
  выровнены на те же 40/32px через `h-10`/`sm:h-8` с `border-transparent` у
  неактивных. Проверено: 320px — без переполнения, пилюли в две строки;
  390px — все цели ровно 40px; 1556px — без изменений (32px).

### 3. Синтетический жирный Evolventa — ИСПРАВЛЕНО 25.10.2026

- **Где:** `app/layout.tsx:13-24` — два отдельных семейства (`evolventaSans`

- **Фикс:** один `localFont` с `src: [{ path, weight: "400" }, { path, weight: "700" }]`.
