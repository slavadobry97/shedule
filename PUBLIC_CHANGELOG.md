## [0.1.9] - 23 октября 2026

### Редизайн панели отладки и ИИ-помощника
- **Новый вид `/debug`**: единый список проверок, обзор, записи, журнал и история изменений в стиле «островов».
- **ИИ-чат (A+C)**: контекстная шапка «Смотрю: <вкладка>», карточки-подсказки, плотный лог без пузырей, ответы markdown-блоками с таблицами.
- **Автодополнение команд**: при вводе «/» показывается список (`/очистить`, `/помощь`, `/подсказки`) с описаниями, навигация стрелками.
- **Подсказки повторно**: кнопка «Подсказки» и команда `/подсказки` раскрывают готовые вопросы после начала переписки; `/помощь` показывает их сразу.
- **Модель**: выбор из белого списка, «Авто» — проверенная бесплатная по умолчанию, сохранение выбора.
- **Вкладки `/debug`**: контрастный трек на токенах дизайн-системы (`bg-accent`), читаемые активная/неактивные пункты.

### Улучшения дизайна
- Токены Tailwind v4 в `app/globals.css`, миграция на Hugeicons, пакет `cn`.
- Полотно страницы `--canvas`, тёмная тема, движение и тактильная отдача по HIG.
- Витрина `/design`: тюнер темы, палитра, типографика, компоненты, иконки.

### Инфраструктура
- Серверный кэш расписания (TTL 60 с, дедупликация, ETag).
- Серверная фильтрация по группе, запрет эмодзи.
- Защита `/debug`: пароль, статус ключа, лимит запросов, понятные ошибки ИИ.

## [0.1.8] - 09 февраля 2026

### Новая тепловая карта аудиторий (Heatmap)
- **Визуализация загруженности**:
 - Вместо скучного списка теперь интерактивная мозаика.
 - Цветовая кодировка (зелёный/жёлтый/красный) мгновенно показывает, какие аудитории свободны, а какие перегружены.
- **Детальная аналитика**:
 - При наведении на аудиторию появляется "штрих-код" активности по дням недели.

- **Удобство**:
 - Сортировка по номерам аудиторий для быстрого поиска.
 - Адаптивный дизайн для любых экранов.
 - Правильные склонения ("5 пар", "1 пара").

## [0.1.7] - 09 февраля 2026

### Улучшенный мобильный UX
- **Карточки дней недели**:
 - Карточки теперь статичны и отцентрированы для удобства.
 - Убрано горизонтальное прокручивание дней, все дни (Пн-Сб) видны сразу.
 - Свайпы (перелистывание) теперь работают только на области расписания, исключая случайные переключения при касании дней.
- **Взаимоисключающие фильтры**:
 - При выборе группы фильтр преподавателя автоматически сбрасывается, и наоборот.
 - Если сбросить оба фильтра, приложение автоматически возвращает на экран приветствия.

### Умные уведомления
- **Тихий старт**:
 - При первом запуске или очистке данных уведомления больше не приходят ("спам" о добавлении всего расписания устранен).
- **Точечные оповещения**:
 - Уведомления приходят **только** если выбрана конкретная группа или преподаватель.
 - Если фильтры не выбраны, уведомления вас не побеспокоят.

### Исправления и оптимизация
- **Watchpack Error**: Исправлена ошибка отслеживания системных файлов Windows (`System Volume Information`), ускоряющая старт разработки.
- **Шрифты**: Исправлены ошибки 404 при загрузке шрифтов.
